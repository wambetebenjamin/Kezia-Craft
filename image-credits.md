## Notes

- Images were downloaded from Pexels at the largest size available and saved at JPEG quality 82 with
  metadata stripped and progressive encoding.
- Pexels photography was used instead of AI generated imagery, and no watermarked or paid tier
  images were used.
- Some files intentionally reuse one source photo (for example `beadwork-cover.jpg` and
  `beadwork-cuff.jpg`) so a product and its artisan share the same visual language.
- If a maker asks for their photograph to be replaced, drop a new file into `/public/images` using
  the same filename and update the table above.
